# Profile setup

Live at <https://github.com/TheNonConformist/TheNonConformist>.

## What updates automatically

| Workflow | Schedule | Output |
| --- | --- | --- |
| `pixel.yml` | daily 02:20 UTC | `stats-pixel.svg`, `contrib-pixel.svg`, `quests-pixel.svg` |
| `snake.yml` | every 12h | `output` branch → `github-snake.svg`, `github-snake-dark.svg` |
| `activity.yml` | daily 02:45 UTC | recent activity block in `README.md` |

All three can be run manually:

```bash
gh workflow run pixel.yml
gh workflow run snake.yml
gh workflow run activity.yml
```

## Secret

`METRICS_TOKEN` is a classic PAT with `repo`, `user`, `workflow` stored as an Actions secret.
Rotate it at <https://github.com/settings/tokens> and update:

```bash
gh secret set METRICS_TOKEN --repo TheNonConformist/TheNonConformist
```

## Customize

- Hero (live): `assets/hero-nightshift.svg` is generated by `tools/gen_nightshift.py`.
  Edit the scene, then run `python3 tools/gen_nightshift.py`.
- Alternate hero: `assets/hero-pixel.svg` (PLAYER ONE character sheet) is generated by
  `tools/gen_hero.py`. Swap the `<img src>` in `README.md` to switch.
- Pixel cards: `tools/gen_profile.py` builds the stats, contribution and quest SVGs from
  the GitHub API. Run `GH_TOKEN=... python3 tools/gen_profile.py` to refresh locally.
- Accent palette: constants at the top of the three generators (`ORANGE`, `CREAM`, `GREEN`).
- Activity feed: `.github/recent-activity.config.yml` (`max_lines`, `disabled_events`, `ignored_repos`).

## Known issues

- The pixel cards are generated with `METRICS_TOKEN`; if it expires, the daily job fails and
  the last good SVGs stay in place.
- Language percentages are byte totals across non-fork public repos. They will show Python/C
  until C++/CUDA code is actually pushed.
- The old metrics and 3D workflows were removed; their generated assets remain in the repo
  as legacy files and are no longer referenced by `README.md`.
- GitHub's achievement display queue can lag by days; see community#203416.
